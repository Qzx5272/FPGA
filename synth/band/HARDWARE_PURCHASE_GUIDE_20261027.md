# 星群扩展硬件选型与接线分层

本文件用于采购/布线计划，不是本轮 FPGA 扩展板卡管脚表。引脚要以手上 Tang Mega 138K Pro 的具体 PCB 修订号和原理图复核后再落 CST。不要凭本表将 5 V 接入 FPGA IO。

## 分开规划：电源与通信/信号

**电源层。** FPGA 按开发板原厂规格使用其输入电源。ESP32-C3 SuperMini 和 Teensy 4.1 初次调试分别由 USB 供电，FPGA 只通过 UART 信号联通；公共地相连，不把多个 USB 的 5 V 输出互接。模拟 ADC/压力传感器、DAC 的供电应从确认额定电压和总电流后的稳压支路取得；模拟/数字回流按实际模块做短回路与单点参考。USB Host 端若打击垫或 Hub 耗电较大，用有源 Hub。不要用 FPGA GPIO/开发板 IO Bank 给外设供电。

**通信/信号层。** BLE 桥使用 ESP GPIO4 TX→FPGA UART RX、GPIO5 RX←FPGA UART TX、GND↔GND，1 Mbaud、3.3 V TTL；FPGA 的实体扩展头号目前未确认。USB-MIDI 桥使用 Teensy 4.1 Serial1 的 pin 1 TX→FPGA UART RX、pin 0 RX←FPGA UART TX、GND↔GND，1 Mbaud。MIDI 打击垫接 Teensy USB Host 口。外置 I²S DAC 接 FPGA 的 BCK/WS/SD，再接模拟放大/音箱；I²S 麦克风 SD 回 FPGA，并从 FPGA 输出的 BCK/WS 取时钟。I²S 时钟和扩展管脚需单独审查。

## 当前采购结论

你已说明有 ESP32-C3 SuperMini 和 4×4 USB 打击垫。先用现有设备；优先核实垫是否 class-compliant USB-MIDI，并准备 Teensy 4.1/USB Host 路径。若使用16只自研FSR，选择已实现的3片MCP3208精简导出；完整64垫配置另用10片。不要为已有USB垫再购买64只FSR。最终器件/IO电平和引脚仍需实物复核。

精简导出逻辑映射：ADC0 CH0–7→垫0–7；ADC1 CH0–7→垫8–15；ADC2 CH0–3→主奏/贝斯/键盘/合唱表情，CH4–6→主奏/贝斯/键盘弯音，CH7→合唱元音。ADC2不会被识别成额外压力垫。三片共用CS/SCLK/DIN、各自独立DOUT；板端物理引脚未指定。未使用的模拟输入不要悬空，按ADC数据手册处理。

若只用现有USB垫和脉冲编码器，选择“V6 USB16垫 + 脉冲旋钮 · 无ADC”导出。此配置已移除ADC/本地模拟脚踏实体端口，禁用模拟采集前端；数字编码器、BLE/USB UART、播放/停止按钮仍保留。它的完整顶层展开和无模拟误触源检查通过。**此路线无需购买FSR或ADC**；可选延音踏板接Teensy GPIO2，标准I²S/DAC等其余扩展仍需真实引脚审核。

冲标准 I²S 需准备 DAC、24.576 MHz 时钟和 3.3 V I²S 物理连线；但先从实物原理图确认可用 IO 和时钟输入，避免买错接口/电平板。PCM5102A、麦克风、ADC、编码器、LED 目前都没有对应的安全 CST，软件测试不代表已完成接线或供电验证。
