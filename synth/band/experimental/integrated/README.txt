星群 FPGA 整合工程 — 2026-11-01

硬件：Tang Mega 138K / GW5AST-LV138FPG676AC1/I0，50 MHz。
屏幕沿用 J20 的 800×480 RGB666 面板。外部数字信号集中在 J23。
无独立 LED。PCM5102 使用标准 I2S；板载 PT8211 功放使能关闭。

交付状态以发行目录中的 status.json 和 fpga/audit.json 为准。
仿真通过不等于烧录验证；时序通过不等于音频质量、温升或冷启动验收。

供电与公共地
ADC 的 TX3 接对并不够，ADC GND 必须直接接系统公共地。
不得依靠两根 USB 经电脑形成的间接地连接。
C3、ADC、FPGA、DAC、麦克风及控制面板全部共地。
C3 和 ADC 可各用 USB 供电，不把它们的 5V/3V3 输出互相并联。
J23 本身没有 3.3V：可从已核对的 J24-1 取 3.3V、J24-3 取 GND，
或另加经过验证的 5V->3.3V 稳压分配；不能把 J23-11 当作 3.3V。
INMP441 VDD 用 3.3V，L/R 接 GND，不能接 5V。
PCM5102 模块是否可从 VIN 输入 5V，取决于模块上的稳压电路；
不能把 5V 接到芯片本身的 3.3V 电源脚。
PCM5102 SCK/MCLK 按已验证模块配置接地；H1=L、H2=L、H3=H、H4=L。
DAC 的 L/R/GND 接有源音箱的线路输入；本工程不直接驱动无源喇叭。

控制面板
每个独立按钮：一端 3.3V，另一端为上述输入，并以约 10k 电阻下拉到 GND。
编码器 A/B 公共端接 GND；SW 按下接 GND，输入有上拉。
按实体面板编号：
1 号转动调速度；短按恢复当前声部表情，长按切换模式。
2 号转动调表情；短按翻页。
3 号转动选声部；名称随转动刷新，短按选上一首。
4 号转动调起音；短按选下一首。
5 号转动调释音；按键未接。
6 号转动调总音量；按键未接。
注意 Attack 存储的是包络步进，数值越大起音越快。
电子歌手声部的参数能力不同，支持音符/力度/表情，不承诺 Attack/Release 生效。
摇杆 X/Y 暂不使用；只接 SW。SW 按住延音，松开释放已松键的音符。
面板八度和摇杆延音作用于 C3 实体垫；内置伴奏和手机 source3 的音符保持各自控制。
八度范围 -3..+4，仅改变后续旋律音符；打击乐声部 0..2 不移调、不延音。
停止不等于暂停；播放键从曲首重新开始。

四个推子
推子两端接与 ADC 同时上下电的 3.3V 和 GND，滑动端依次接 ADC AIN0、AIN1、AIN2、AIN3。
优先使用 ADC 板自身的 3V3 稳压输出，先确认该端为输出且实际电压为 3.3V；
不要将它与 FPGA 的 3V3 电源输出并联，也不要在 ADC 断电时继续向 AIN 灌入电压。
映射：AIN0=贝斯(3)，AIN1=电钢琴(4)，AIN2=主奏(6)，AIN3=合唱(7)表情。
AIN4～AIN9 未使用。输入不得超过 3.3V。
实测约 3.0V 行程，2.921V 起达到最大值 127。推子采用接管机制：经过当前参数附近后才控制，避免上电参数跳变。
数据 500ms 未更新时显示离线并撤销接管；恢复数据后重新接管。
USB 实测 COM9：460800 baud, 8N1，约 20 帧/s。
帧：<v>:0.426,3.269,3.269,3.281,0.953,0.574,0.489,0.479,0.479,0.467 后接 LF。
完整十通道校验后一起提交；非法数字、超过 3.300V、残帧不提交。
TX3 经 J23-3 -> FPGA -> PC 的实物透传验证也已通过：
首次 3s 收到 60 帧；清空串口缓存后 2s 收到 40 帧、2560 字节，无多余或损坏字节。

C3、手机与录制
C3 GPIO4 TX -> J23-1，GPIO5 RX <- J23-2，GND -> 公共地，UART 1Mbps 8N1。
实体 MIDI 垫使用独立席位 source2；手机沿用 source3，互不冒用身份。
C3 通过 FPGA 返回的 A3 配置同步声部、八度、延音和录制请求。
切换声部释放旧音符并申请新声部；必须得到真实所有权应答才发音。
每个松键使用起音时保存的声部、音高、epoch、serial，避免切换后的挂音。
新版 C3 必须与整合 FPGA 配套；旧固件不会响应新增面板配置。
短录制保存在 C3 RAM，最多 512 个音符事件，断电丢失；不录麦克风或歌曲音频。
记录实体垫已发送的音符，包括延音造成的延迟松键；不录手机席位或面板参数。
回放须选择录制时的同一声部；回放使用当前所有权与新 serial。
实体垫弹奏会停止回放；MIDI 时钟不会停止回放；结束/断线/总停会释放音符。
切换声部结束当前录制；满缓存结束录制，界面 FULL=1。
手机 APK 是沿用版本，新增面板参数由 FPGA 屏幕展示，不宣称手机新增完整编辑页。

音频、麦克风与屏幕
48kHz，双声道 PCM16，I2S 每帧 64 BCLK；麦克风采集左声道 PCM24。
同一内部时基分别驱动 DAC 与麦克风的物理时钟脚，避免异步采样漂移。
启动先等待麦克风约 171ms；停止清音频队列但保持麦克风时钟连续。
模式 0 为关闭（上电默认），1 为监听，2 为电子歌手，3 为跟灯学习。
模式 2 需要声部 15 的旋律音符作为载波；仅对麦克风说话不保证有声。
有源音箱与麦克风形成反馈回路时可能啸叫；实测必须从低音量开始。
屏幕上半部显示最后收到的音符、当前选中的乐器、活动声部、音量和速度。
下半部显示当前所选声部、八度、延音、采集状态和页面，以及表情/包络、推子接管、
麦克风、歌曲状态。录制、回放、已满和片段状态 来自 C3 状态应答。
MIC READY 表示采样时钟暖机结束，不是物理麦克风在位检测。
实物诊断已验证 J23-8/37/38 的 INMP441 采样：3235 帧，校验错误 0，
序号丢失 0，采样有正负变化。该诊断以 48kHz 采集、1kHz 抽取回传，
证明数字采样链路接通，不等同于完整监听/电子歌手的音质验收。
触发高亮是收到起音事件的短暂提示，不是精确的持续按键或声音检测。

验证与后续验收
离线检查覆盖：ADC 解析、有效高电平按钮、去抖、推子接管、参数声部身份、
64-slot I2S、70ns 三态麦克风模型、音频队列、C3 延音/录制/身份、完整引擎和屏幕像素。
厂商时序必须检查 setup/hold/pulse、全部约束生效、管脚/电平/驱动和位流完整性。
出现异常发热或糊味时先断电排查，不进行热插拔复现。
本次烧录与实测结果见 status.json 和 evidence 目录；已完成的步骤不必重复执行。
日常使用：给 FPGA、C3、ADC 供电，唤醒实体垫，等待屏幕启动后按播放键。
C3 已写入固件后不需要持续连接电脑 USB，独立供电并保持 UART 与公共地连接即可。

跟灯学习《小星星》
当前面板选第 4 套预设、Bank 2，默认 16 个垫发出通道 10 的音符 20～35。C3 v8.3 会核对型号与记录，清除 PAD 9～16 的出厂控制键分配，并回读确认。原有音符配置保留。
实体 1 号旋钮控制模式。长按约 1 秒并松开，每次切换一个模式，进入模式 3 即可跟灯。
同一 FPGA 八度下，16 垫使用同一底色；默认青绿。按下的垫显示白色，松开后恢复。学习目标为黄色。C3 和 FPGA 分开测试时，C3 不会收到学习模式指令。
一次敲击只推进一个音，遇到连续相同的音时须先松开再敲。节奏可按自己的速度练习。
声部使用拨弦，八度为零，表情为 110，发音力度为 96。总音量仍可调节。
再长按同一旋钮退出学习。退出或完成后目标提示消失。重新连接时，C3 重新读取设备配置并刷新底色。
