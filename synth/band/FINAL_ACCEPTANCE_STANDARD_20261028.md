# 星群 FPGA 乐器整机最终验收标准

版本：2026-10-28。本文是后续执行标准，不是已通过的报告。

适用目标：能够脱机演奏，具有多音色、实体控制、编排、事件录制重放、手机联动和现场展示能力的成熟参赛原型。

当前基线：`pt8211_dvi_8994dbe5e358`，build ID `539365416`。当前证据属于原生 PT8211 固定引脚配置；扩展源码或综合结果不能代替扩展整机验收。

## 一、规则与放行条件

**依据分为三种，不能混用：**

- 用户需求：本轮明确提出的功能，必须交付。
- 赛项暂定要求：来自工程 `reference/官方要求追踪.csv` 的 O01–O10。正式赛题原文尚未核实，不能据此断言官方强制项、分值或满分。
- 工程门槛：本文提出的测试数量、性能和可靠性要求，用于判断是否达到成熟原型，不冒称官方规定。

**最终只验收一套锁定的配置。** 验收封面记录板卡修订、外设型号、接线图、供电、时钟、约束、位流 ID、上位机和桥固件版本。不能拼接不同配置的时序、复音、I²S和长稳成绩。

每项结果只能填写：**通过、失败、待测、不适用**。“不适用”须说明范围，不能删除已确认的必需需求。仿真不能替代真实外设，遥测不能替代模拟音频测量。

| 等级 | 放行含义 |
|---|---|
| L1 软件交付版 | 源码、主机功能、相关仿真和构建通过 |
| L2 板级可运行版 | 对应配置时序/引脚、SRAM、Flash和真实板级数字回归通过；当前V6原生配置属于此层 |
| L3 整机最终版 | 本文所有必需功能、实体外设、性能、异常和可靠性项目通过 |
| L4 参赛提交版 | L3通过，正式赛题逐条复核，答辩、材料与复现通过；仍不保证100分或获奖 |

以下任一问题阻断 L3：电平/引脚错误、时序失败、崩溃、卡音、授权串扰、正常负载丢样、作品或录音静默损坏、已宣传必需功能不可用。

## 二、硬件、供电与接线（H）

| 编号 | 验收内容 | 通过条件 | 必要证据 |

| H02 | 供电独立规划 | 电源图列明每路电压、电流预算与实测；无多个USB 5V输出互接，无GPIO给大负载供电 | 电源树、测量记录 |
| H03 | 信号独立规划 | 每根线对应实物接口脚号、原理图、CST及IO Bank电压；TX/RX交叉、共地、电平兼容 | 审核接线表、Pin报告 |

H05/H06按最终路线选，不要求同时购买两套。成品USB垫不能自动证明“自研压力交互”成立。

## 四、演奏、音色、歌曲与电子歌手（M）

| 编号 | 验收内容 | 通过条件与方法 |
|---|---|---|
| M01 | 自动演奏连贯性 | 同曲、同BPM比较修改前后；标注有意休止；非休止衔接无调度造成的意外空白、漏音、卡拍；至少两人完整试听并记录意见，不粗暴填满所有休止 |
| M02 | 细步长 | 1/16、1/32、三连音及已支持的自由时间编辑正确换算；保存/载入/上传时间一致，网格细化不改变采样率 |
| M03 | 四类乐器 | 弦鸣式、气鸣式、膜鸣、体鸣每类至少一个真实可演奏预设；15预设逐个测试有效音域低/中/高音和三档力度；包络/谱形可辨，不能同波形改名 |
| M04 | 音准 | 在声明音域抽查至少12音；无弯音/调制时，稳定音高误差工程目标≤±5音分；鼓/非谐波钟声按声明调音模型测量 |
| M05 | ADSR | 改变A/D/S/R，实际包络符合模型；极值不导致非法值、永久不释放或丢样；量化误差、范围及限制有说明 |
| M06 | 力度与表情 | 测力度1/32/64/96/127；力度、弯音、表情等至少3维可独立控制，映射清楚，极值合理，连续参数无明显阶跃爆音 |
| M07 | 音色切换 | 每个宣称支持的声部切换成功；保持音符时切换的尾音策略明确，无卡音、错轨、异常突发声；独立轨道算法仅在对应扩展验证后宣称 |
| M08 | 基础与扩展复音 | 基础≥4独立音高；暂定拓展≥32独立音符或≥32加法分量，二者分别记录；若宣传256音符，需256独立身份和参数负载测试，槽数不能代替独立音高证据 |
| M09 | 重复演奏 | 相同事件的确定性行为符合设计；随机音源以固定种子做数字回归，真实噪声音色不要求每次样本完全相同 |
| M10 | 多曲持久化 | 3首完整事件曲目可选、可开始/停止、正常结束；ROM曲库断电保持；RAM上传不持久有明确提示；不要求必须使用SD卡 |
| M11 | 人机协作 | 接管一轨不打断其他轨；独立身份互不误释放；量化归还、再次按下取消归还和多人同时演奏符合明确规则 |
| M12 | 节拍/控制 | BPM、循环、节拍器及声明支持的暂停/停止/重启行为正确；不随GUI刷新率漂移；停止重播不冒充暂停续播 |
| M13 | 电子歌手 | 有限元音/乐句按音高节拍发声；元音变化可辨；真实麦克风声码器输入能够改变输出，静音及断钟安全；不能宣称任意歌词自然演唱 |
| M14 | 混音/效果 | 逐轨音量、静音、独奏及声明支持的声像正确；延迟/混响/合唱有实际FPGA输出A/B证据；旁路、反馈极值、尾音无溢出或异常极限环 |

## 五、实体控件、手机和显示（I）

以下次数为工程验收标准，不是已核实的官方规定。

| 编号 | 验收内容 | 通过条件与样本量 |
|---|---|---|
| I01 | 16个打击垫 | 逐个验证映射、NoteOn/Off及力度能力；每垫100次，0错映射/漏释放/卡音；同时至少4垫，邻垫不误触 |
| I02 | 压力能力 | 只有NoteOn velocity就不称持续压力；FSR逐垫校准基线/阈值/迟滞和轻中重；声明支持触后/持续压力则实测 |
| I03 | 8个脉冲旋钮 | 主音量、速度、表情、声部、起音、释放、效果、元音逐路验证；慢/快、正/反、按压按规格响应；每路累计500档定位转动，无错误方向、静止跳变，边界限幅正确 |
| I04 | 自研交互维度 | 至少两种维度分别改变，其他维度保持，原始值和声音可对应；保留自研硬件/RTL证据；8个同类编码器是否计作多维须对齐正式规则 |
| I05 | 脚踏 | 用途明确为延音、接管/归还或表达；极性/去抖正确；松开无残留；延音与接管语义不能混淆 |
| I06 | USB Host | 真实USB垫冷启动枚举和运行拔插/恢复各20次；断开无僵尸音符，重连不沿用旧授权 |
| I07 | BLE手机 | 实刷C3，至少一台指定真实手机/系统/浏览器完成配对；16垫、参数、开始/停止可用；断链/恢复20次无卡音；不称蓝牙音频 |
| I08 | 手机兼容 | 实测分包、权限、导出、弱信号和后台/锁屏；不支持Web Bluetooth的目标系统有替代客户端或明确支持范围；网页能打开不等于联动通过 |
| I09 | 真屏显示 | 频谱/电平来自实际合成PCM；已知测试音峰位置正确；改变音高/音色时随声音变化，停音按窗口/尾音消退 |
| I10 | 脱机LED | 不接电脑/手机可选曲和完整演奏；当前/下一音、节拍定义明确，LED与曲目一致；3首各完整演示一次，电脑屏幕不代替LED |
| I11 | 多输入并发 | 垫、旋钮、电脑、手机同时操作10分钟无串轨/误抢/双触发；优先级和声部选择规则明确；独立的选轨状态不能宣称自动同步 |

USB垫路线不需要额外FSR/ADC；脉冲旋钮A/B也不需要ADC，但同步、去抖和电平匹配必须通过。

## 七、声音质量与性能（P）

下列数字是本项目建议工程门槛。正式赛题有不同要求时，更新适用范围与门槛后执行，不能将轮询时间或渲染周期直接当端到端延迟。

| 编号 | 指标 | 测量与通过条件 |
|---|---|---|
| P01 | 端到端延迟方法 | 固定快速起音测试音色，记录真实垫触发/接点或电气事件t0及DAC模拟输出超过已记录噪声门槛的t1；1000次覆盖空载/典型/最大声明负载，报告最小/中位/P95/P99/最大；附t0定义、阈值、包络与波形，不隐去机械/USB延迟 |
| P02 | 有线延迟 | 本地自研有线输入冲优目标：1000次最大≤5ms；USB-MIDI目标最大≤10ms。暂定O04≤10ms、O08≤5ms的适用范围须正式规则解释；不能拿P99替代最大值，失败不能偷偷改口径 |
| P03 | BLE延迟 | 无线另测1000次，目标P95≤30ms、最大≤50ms；记录距离、手机和干扰；这是工程目标，不能替代有线门槛 |
| P04 | 丢样/期限 | 声明负载下30分钟混合演奏、效果、显示和通信，deadline miss、DAC dropped、underrun及队列溢出无新增；预热和计数重置注明 |
| P05 | 削波/余量 | 标准曲、典型和弦和声明最大负载在规范音量下无非预期削波；记录复音/力度/总增益/限幅策略；极端叠加有保护，不要求数学上不可能的无限幅无损相加 |
| P06 | 噪声/失真 | 在规定负载与增益下用校准正弦测线路输出，目标信号相对静音噪声≥60dB，1kHz正弦THD+N≤1%；注明带宽、仪器底噪。该门槛测链路，不要求鼓/失真预设是正弦 |
| P07 | 爆音/直流 | 100次开始/停止、切音色、连续调参、断链和正常电源流程，无明显非音乐性爆音；直流符合DAC/功放规格，静音无异常持续噪声 |
| P08 | 实际听感 | 正常监听音量下，低/中/高音与力度无非预期毛刺、错音、破音或截尾；两名使用者记录整曲、四类音色和效果A/B意见 |
| P09 | 独立负载 | 音符数/加法分量数分别报告；独立频率集合验证谱峰、同音重叠独立释放、跨轨控制和效果满载；32音高重复占256槽不等于256可辨谱峰 |

仪器无法支持P06精度时填“待测”，不能凭听感判定数值达标。慢起音音色的音乐性ADSR时长单独记录，不以扣除未知延迟的方式美化P01。

## 八、异常、恢复与可靠性（R）

| 编号 | 验收内容 | 通过条件：工程标准 |
|---|---|---|
| R01 | 总停音 | 100次含满载/延音/尾音，FPGA接受panic后20ms内归零或按声明安全斜坡静音；实测模拟输出。GUI到FPGA接受的排队/通信时间另记，不隐藏 |
| R02 | 断链 | USB/BLE/串口各20次，回收该来源保持音符；当前500ms租约设计目标600ms内开始释放，并在设定Release上限内结束；其他来源不误清，延音优先级明确 |
| R03 | 身份/权限 | 错来源、旧epoch/serial、重复释放、非法part/参数、越权上传/panic不能破坏其他席位；拒绝计数和原因可查 |

## 十、范围边界与执行记录

独立EQ、真正单声部legato/自动滑音、SD/FAT大曲库、WAV直录、USB音频、任意歌词自然演唱、完整商业DAW、MPE等，不默认纳入当前版。若决定纳入或对外宣传支持，必须增加实现及验收。正常连贯性、延音、表情、四类音色、保存恢复和异常停音仍为必需项。

每项记录：编号、日期、执行/复核人、硬件配置、位流/软件版本、输入和负载、步骤、预期、实测及最大值、结论、证据文件、缺陷与复验。保留原始波形/数据，不只留结论截图。

推荐顺序：正式规则/最终配置 → 电源/引脚审核 → 完整构建及零违例时序 → SRAM音频 → 实体外设 → 音色/曲目/效果 → 录放/保存/上传 → 音质/延迟/负载 → 异常/脱机/冷启动/长稳 → 最终Flash与短回归 → 答辩和复现。

只重复改动相关项和必要发布回归，不重复无影响模块的长测或仅为检查而反复计算哈希。

## 十一、当前距最终版的缺口

已有证据：原生PT8211版105项上位机测试、18固定引脚零违例时序、SRAM数字回归、256槽/整曲、实际Qt音色及事件录放、Flash校验和重载身份；扩展有源码、RTL及部分综合证据。
