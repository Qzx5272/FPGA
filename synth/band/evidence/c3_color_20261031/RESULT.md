# C3 → SMC-PAD Pocket 颜色编辑实测

日期：2026-10-31。状态：单垫颜色修改已通过设备回读与用户目视双重确认。

- C3：COM8，ESP32-C3 rev0.4，MAC 80:53:e0:9f:43:c4。
- 打击垫查询应答：SMC-PAD Pocket_004。
- 通过 C3 的 AE40/AE41/AE42 厂商 GATT 通道编辑，保留 BLE MIDI 接收。
- 读取并校验了 4 × 2931 = 11724 字节的四组预设配置。
- 目标：零基预设3、槽20，即第4组预设的音符24、MIDI第10通道。
- RGB地址：9318（0x2466）。原值 FA0000，新值 0000FA。
- 写入请求：0059220B000005662400000300000000FA73。
- 应答：00590001000000FF。
- 修改后完整回读仅有两字节差异：9318处250→0，9320处0→250；其余字节不变。
- 用户确认：“看到了，一个垫变蓝了”。蓝色保持，未自动恢复。

备份：prewrite_confirm.bin；回读：after_color.bin；串口证据：color_write.log。
恢复同一个垫的原色命令：`color 3 20 250 0 0`。

限制：尚未验证掉电持久性、全16垫映射、快速灯光动画、手机并发或FPGA发声。
普通SMC-PAD与Pocket配置地址不同；本次地址由Pocket实际读取数据核对。
