更新：2026-10-26。工程候选，最终目标未完成；没有发布新的整机位流。

1. 最终目标
实现可多人演奏、机器协作、脱机运行、可测可用性能的 FPGA 电子乐队：鼓、贝斯、和声、主奏、合唱/电子歌手、指挥混音。先完成音色效果、整曲协作与可控演出，再验证容量和长期稳定性，最后全局优化。任意歌词自然歌唱不是当前提交版关键依赖。
256个乐队槽当前分八组、每组32槽，并非自由全局池；另有独立单声部电子歌手。43008独立分量只属于独立诊断配置，不能当作完整乐队容量或芯片上限。

5. 上位机和复现
在解压后的project目录执行：
  python -m pip install -r synth/band/requirements-host.txt
  python synth/band/host/app.py
本机Python为.venv/Scripts/python.exe。ASDFGHJK八键入口，调式/八度切换，MIDI按席位分配，Ctrl+Space总停音。先核对固件ID、低音量排练。
UART为64个帧外零字节保护，每5ms最多4事件，不支持未经保护的裸高速突发。
编辑器保存JSON曲谱、音色、元音、校准与映射。RAM上传断电丢失；导出源码仍需正确约束、构建和下载，才可脱机演出。
关键工具：test_host.py、test_vocoder_filterbank.py、test_vocoder_core.py、test_vocoder_netlist.py、export_workstation.py、build_combined_workstation.py、build_combined_workstation_timing.py（均在synth/band/tools）。先读各工具参数和证据范围。
所需环境：Python依赖、Gowin1.9.12.03、OSS CAD/Icarus/Verilator、MinGW g++。工具默认路径需要按接手机器调整，包内不分发厂商工具及环境。
上游许可证和变更：synth/band/experimental/vocoder/upstream/LICENSE、PROVENANCE.json。
