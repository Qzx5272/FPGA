一、目标和开发顺序
目标是一套可多人演奏、机器协作、脱机运行的FPGA电子乐队工作站。电子琴/MIDI垫只是演奏入口。
按音色效果、完整乐队闭环、性能实测、人声增强推进；功能成立后再全局优化。任意歌词自然歌唱不作为当前提交版的关键依赖。
最终仍需鼓、贝斯、和声、主奏、合唱/电子歌手、指挥混音；支持逐轨进入/静音、人工接管与归还、保存和脱机演出。

四、上位机怎么运行
在解压后的project目录创建Python环境，安装 synth/band/requirements-host.txt：
  python -m pip install -r synth/band/requirements-host.txt
  python synth/band/host/app.py
本机可用 .venv/Scripts/python.exe。串口连接后先看构建ID，再从低音量排练。
ASDFGHJK为八键入口，调式和八度可切换。MIDI按演奏席分配；CC64延音按席位/通道隔离。
Ctrl+Space为总停音。通信使用64零字节保护、每5ms最多4事件；不支持未经保护的裸高速突发。
主机来源1..4，本地ADC来源17..20。脚踏保持控制权，松开最后一个垫仍释放音符；抬脚后按小节归还机器。
歌手轨只开放已支持的音符/力度/表情，不把未实现的歌手弯音/元音/ADSR当成可用能力。

五、舞台反馈
舞台页显示FPGA回传的轨道归属和全局状态，不从图形猜测逐轨音量或歌词。
“音频输入·波形/频谱/李萨如”由用户手动开始；监测FPGA模拟输出需实际连接线路输入/声卡。
它不录制、不回放、不参与音源合成；超过0.5秒无采样会清屏，关闭窗口/演奏台结束采集。默认没有采集。
硬件PCM快照已经接到实验融合顶层，显示停顿不会背压音频；2048点周期Hann窗与定点FFT已接通，并逐点对比实际乐队PCM；停分析时钟期间总停音、恢复后撤销旧结果通过。约48.65ms整机数字联调零丢样/欠载/超期；逐频点最大实虚误差约6.55LSB。分析版本尚未布局布线；视频/HDMI/物理显示仍未完成。

六、保存和脱机导出
保存的是事件曲谱、音色参数、映射/校准与启动设置，不以预录音频替代FPGA合成。
RAM上传曲谱断电丢失；运行时非易失保存未实现，Flash开机恢复未做物理验收。
编辑器先选电子歌手角色，再点“导出融合工程”；或：
  python synth/band/tools/export_stage.py synth/band/assets/confluence_singer.json <空目录>
默认上电自动演出，--manual-start等待播放。实际导出顶层192采样冷启动仿真通过，不等于物理断电测试。
必须配置真实microphone.cst/.sdc和stage.cst/.sdc。声明检查不证明引脚冲突、电压和外部时序正确。
当前流水线校准源码导出例为offline_stage_pipelined_confluence；selector及更早目录为历史快照，不能混用验证成绩。

九、合并工作站新增能力与验证边界
band_workstation_top将本地席/脚踏、歌手/乐队、I2S队列/断钟保护、2048点Hann/FFT和频谱帧缓存接在同一顶层；短场景联合仿真比对实际串行音频与频谱，验证显示停顿、音频断钟及明确重启。尚无该合并顶层的整曲、满载或布局布线验收，不能借用PT8211顶层通过成绩。
工作站在缺失音频时钟时保持停音；独立心跳恢复后才允许发声，断钟清场后不会自动重放旧音符。已修复从上电起音频时钟就缺失时的心跳初始化问题；供应商网表保留全部8个初值。
上位机“导出 I2S 工作站”要求第16轨选择电子歌手，保存曲谱和当前参数；也可运行tools/export_workstation.py。最新示例为offline_workstation_clockwait_confluence，早期offline_workstation_confluence已被替代，不随新包交付。
实际导出顶层通过192采样冷启动测试：无UART，等待时钟后自动执行一次，音高/表情/混音预置一致，断钟恢复后不自动重演；不是96秒实物冷启动验收。缺少workstation管脚/时序文件时供应商构建被阻止。
外部I2S需要24.576MHz音频时钟及实际DAC；16位源补零到24位传输，板载PT8211功放禁用。频谱读取是冻结RAM协议，不是已经完成的HDMI显示。未知外设管脚未猜测，Flash未改写。
