更新：2026-10-26；状态：工程候选，最终目标未完成，未发布新的整机位流。

1. 最终目标与当前边界
作品是一套可多人演奏、机器协作、脱机运行、能实测可用性能的 FPGA 电子乐队。鼓、贝斯、和声、主奏、合唱/电子歌手与指挥混音都须形成音乐角色。
电子琴和 MIDI 垫只是入口。先做音色与效果、整曲协作，再测容量与长期稳定性；功能验收后再全局优化。任意歌词自然歌唱不是当前提交版关键依赖。
256 个乐队音符槽目前按八组各32槽分配，不是完全自由的全局池。电子歌手另有独立单声部；有限元音合唱与麦克风声码器是两种能力。

5. 上位机与复现入口
在解压后的project目录：
  python -m pip install -r synth/band/requirements-host.txt
  python synth/band/host/app.py
本机Python：.venv/Scripts/python.exe。连接后先核对固件ID，从低音量排练。ASDFGHJK是八键入口；调式、八度可切换；MIDI按演奏席分配。Ctrl+Space总停音。
UART使用64个帧外零字节保护，每5ms最多4个事件，不支持未经保护的裸高速突发。
编辑器保存JSON、事件/音色/元音/校准/映射；RAM上传断电丢失。导出源码后仍需正确约束、构建和下载才能脱机演出，尚未证明新整机Flash冷启动。
关键命令：
  python synth/band/tools/test_host.py
  python synth/band/tools/test_vocoder_filterbank.py
  python synth/band/tools/test_vocoder_core.py
  python synth/band/tools/test_vocoder_netlist.py <正确声码器综合目录>
  python synth/band/tools/export_workstation.py synth/band/assets/confluence_singer.json <新的空目录>
  python synth/band/tools/build_combined_workstation.py <正确导出目录>
  python synth/band/tools/build_combined_workstation_timing.py <正确综合目录> --cdc-hold
ROM负例复现test_coefficient_rom_netlist.py预期报告mismatch：二维失败、一维通过；不能把这个负例返回码误判为修复版失败。
工具路径需按接手机器调整：Gowin1.9.12.03、project/tmp/oss-cad-suite、MinGW g++、Python依赖。压缩包不分发厂商工具或环境。
