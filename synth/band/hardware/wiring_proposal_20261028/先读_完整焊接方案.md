## 2. 电源方案：先接电源和地，后接信号

初次联调保持开发板原有原厂供电方式，不在未知修订上新增12V/5V飞线。ESP32-C3和Teensy各自通过USB供电，和FPGA只接公共地及UART信号；不互接它们的5V或3.3V输出。

| 用电部分 | 初期供电方式 | 必须核对 |
|---|---|---|
| FPGA开发板 | 原厂规定电源入口，沿用当前正常供电方式 | 底板型号、额定电压、极性；不能把12V接扩展头 |
| ESP32-C3 | USB-C供电 | SuperMini具体板型；GPIO为3.3V，不接5V逻辑 |
| Teensy4.1 | 板载USB供电 | USB Host总电流；不要同时外接VIN和USB电源而未处理VUSB/VIN关系 |
| USB打击垫 | Teensy Host规范线束；不足时使用合格有源Hub | 符合USB-MIDI；Hub不反向给上游供电 |
| 编码器 | 无源触点；16个A/B上拉由一条确认的3.3V支路供电 | 裸编码器无5V电源需求；带板模块的上拉必须在3.3V侧 |
| I²S麦克风 | 确认的3.3V支路 | INMP441等芯片不能直接吃5V；按实际模块丝印/手册 |
| 时钟模块 | 3.3V CMOS有源振荡器24.576MHz | 供电、OUT电平和OE；无源两脚晶体不能直接替代 |
| DAC模块 | 按该模块手册给VIN/VCC | PCM5102A模块有不同稳压配置，不能统一假设VIN=3.3V或5V；逻辑输入必须3.3V兼容 |
| LED | FPGA低电流驱动，每灯独立限流 | 不接大功率灯带，不把LED直接短接IO |
| 可选ADC | 同一洁净3.3V模拟支路，VREF按3.3V方案 | 实际预算、去耦和模拟回流；仅FSR路线需要 |

J24/J26：原理图**1、2为+3.3V；3、4为GND**。J23：**11为+5V；12为GND**。J23没有可随意当3.3V的电源针。

初版不从J23-11取外设电源；用J23-12作为信号公共地。外设3.3V支路选定后统一布线，不并联不同稳压器输出。板上PMOD 3.3V可以作为低电流无源上拉的来源，但总供电能力须核算，不能默认能带C3、Host或功放。

数字模块电源入口就近放100nF去耦，支路可加合适的4.7–10µF储能；具体以模块自带电路为准。音频与时钟远离USB电源开关噪声，回流短；不要切断必要公共地。各板独立供电时避免一边断电而另一边长期驱动IO造成反向供电，最终应统一上电管理或使用合适的断电隔离缓冲。

## 3. 八个脉冲旋钮：J24和J26

| 旋钮 | 功能 | A接点 | B接点 | 公共C接点 |
|---|---|---|---|---|
| 1 | 主音量 | J24-11 / C24 | J24-12 / B24 | GND |
| 2 | 速度/BPM | J24-9 / E25 | J24-10 / D25 | GND |
| 3 | 表情 | J24-7 / L17 | J24-8 / L18 | GND |
| 4 | 参数目标声部 | J24-5 / H14 | J24-6 / H15 | GND |
| 5 | 起音 | J26-11 / C21 | J26-12 / B21 | GND |
| 6 | 释放 | J26-9 / B20 | J26-10 / A20 | GND |
| 7 | 效果量 | J26-7 / B19 | J26-8 / A19 | GND |
| 8 | 合唱元音 | J26-5 / A17 | J26-6 / A18 | GND |

每路A/B分别接10kΩ上拉到3.3V，共16只。可在进入FPGA前串330Ω，靠输入端预留1nF对地电容位置，先以数字去抖为主；不要随意加大电容使快速转动失真。每个编码器A/B/C用三线到面板，地线必须可靠。

接线示意：`3.3V—10kΩ—节点—330Ω—FPGA输入`，编码器A或B接节点；编码器公共C接GND。裸编码器的C通常在中间，但必须用通断档/型号确认，不能凭外观认脚。

带按压的另外两个SW脚本轮不映射，可以留空并绝缘。转向反了可交换A/B或在软件统一修正；不要交换电源和地。当前解码器按四次合法A/B跳变产生一步，选购和实测应核对编码器每定位档的脉冲数。

## 4. ESP32-C3与Teensy通信：分开的UART，不能并TX

| 外设信号 | FPGA连接器针 | FPGA球位 | FPGA方向 |
|---|---|---|---|
| C3 GPIO4 / TX | J23-1 | U16 | 输入ble_rx |
| C3 GPIO5 / RX | J23-2 | V16 | 输出ble_tx |
| Teensy pin1 / TX1 | J23-3 | U15 | 输入usb_rx |
| Teensy pin0 / RX1 | J23-4 | V17 | 输出usb_tx |
| 两个桥的GND | J23-12或已确认公共地母线 | GND | 公共参考 |

全部1Mbaud、8N1、3.3V TTL。发送端可串100–330Ω，线束尽量短并带地线；这是低压UART，不接RS232电平。

电脑仍使用开发板现有USB串口和原有N16/P15线路，不需要飞线。**不把C3/Teensy的TX并到电脑UART RX，也不把两个桥TX并在一起。** 新版需独立的三路UART顶层。

USB垫插Teensy的专用USB Host接口/配套线束，不能把D+/D−接FPGA普通GPIO，也不能把Teensy用于编程的USB口当Host口。Host接口针序按Teensy官方引脚图和实际线束确认；未确认前不要靠USB线颜色直接焊。

可选常开延音脚踏：一端Teensy GPIO2，另一端Teensy GND，使用固件的输入上拉。不要把脚踏接5V。它与FPGA本地接管脚踏不是同一个功能。

## 5. 标准I²S DAC、数字麦克风与音频时钟

| 信号 | FPGA端 | 球位 | 外设端与说明 |
|---|---|---|---|
| i2s_bck | J23-5 | W21 | DAC BCK/BCLK；同时接麦克风SCK/BCLK |
| i2s_ws | J23-6 | Y21 | DAC LCK/LRCK/WS；同时接麦克风WS |
| i2s_sd | J23-7 | P21 | DAC DIN/DATA |
| mic_sd | J23-8 | U17 | 麦克风SD/DOUT；不能并到DAC DIN线上 |
| audio_clk | J23-39 | U22 | 24.576MHz、3.3V CMOS有源时钟OUT |
| 地 | J23-12/公共地 | GND | DAC、麦克风、时钟共同参考 |

U22在厂商FPG676报告中为`MGCLKT_0/RPLL0_T_IN1/RPLL1_T_IN1`，是专用时钟输入；仍需最终时序/时钟布局验证，不代表完整扩展已通过。J23-40/V22本方案留空，不能当成差分时钟的地。

时钟OUT旁预留22–47Ω源端串阻，初选33Ω，连接尽量短（目标≤5cm）且伴随地线；不要把24.576MHz绕面板走长杜邦线。振荡器的VDD/GND/OUT/OE按实际模块识别，不凭四脚封装外观猜脚。

DAC采用48kHz、左右各32位槽的标准I²S，传输24位、当前合成有效PCM为16位。共享BCK预期为3.072MHz，WS为48kHz。扩展默认`SHARED_MIC_CLOCK=1`：麦克风接同一组BCK/WS，软件顶层的独立mic_bck/mic_ws输入应在封装中处理，不另外再接一个无同步时钟。

如果实际模块确为PCM5102A并使用其三线PLL模式，按数据手册配置：FMT选I²S、XSMT解除静音、SCK/MCLK按三线模式接低，其他模式脚按模块说明设定；这些是芯片逻辑要求，实际模块焊桥/上下拉需先核对。不要把GPIO模式脚随意接5V，也不要误把BCK和SCK当一个信号。

若麦克风为INMP441兼容I²S模块，VDD用3.3V，L/R选左声道（通常接GND，仍核对模块）；数据接J23-8。麦克风SCK是位时钟，而某些DAC板的SCK是主时钟，名字相同不代表功能相同。

DAC LOUT/ROUT/GND接线路输入的有源音箱或合适耳放；不直接驱动无源喇叭，不把模拟输出接FPGA IO。板载PT8211路径保留，但其现有HP_BCK/WS/DIN不作为本外置I²S接点，也不要把两路模拟输出直接并联。

## 7. 播放、停止、总停音与选曲按钮

优先使用板载S0/S1/S2，暂不增加飞线：S0→K16播放，S1→F15停止，S2→G15总停音。Rev1.5原理图还有S3→G16，可在新固件中分配下一首；当前原生发布没有此选曲映射。

板载按钮为上拉、按下接地。扩展引擎的逻辑入口是高有效，新封装需做极性转换，不能直接照内部端口名接线。若面板必须加同功能按钮，可将常开干接点并联在对应板载按键的“信号—地”两节点；先用万用表识别节点，不按四脚按钮的相邻位置猜测，也不外加电压。编码器按压开关同样可作干接点，但需要明确功能后再接。

## 8. 可选FSR压力垫及三片MCP3208

现有USB垫主方案跳过本节，不购买/焊接ADC。只有选择自研16垫或模拟控制时才启用对应导出配置。

| 信号 | FPGA针号/球位 | MCP3208端 |
|---|---|---|
| 共享CS | J23-25 / AA25 | 三片pin10 CS/SHDN |
| 共享SCLK | J23-26 / AA24 | 三片pin13 CLK |
| 共享DIN | J23-27 / Y26 | 三片pin11 DIN |
| ADC0 DOUT | J23-28 / Y25 | ADC0 pin12 |
| ADC1 DOUT | J23-31 / W26 | ADC1 pin12 |
| ADC2 DOUT | J23-32 / W25 | ADC2 pin12 |

上述IC脚号针对MCP3208的16脚封装定义，模块接插件按丝印对应。各片pin16 VDD和pin15 VREF接确认的3.3V；pin14 AGND和pin9 DGND接地；每片近端去耦。CH0–CH7对应IC pin1–pin8。三个DOUT绝对不能并线。

ADC0 CH0–7→垫1–8，ADC1 CH0–7→垫9–16。ADC2 CH0–3为主奏/贝斯/和声/合唱表情，CH4–6为相应前三者弯音，CH7为合唱元音。它们是额外模拟控制，不是给8个脉冲编码器使用的ADC。

单垫起始电路：`3.3V→FSR→采样节点→固定电阻→GND`，按压力变大电压上升。固定电阻可从4.7kΩ/10kΩ候选起，经实物力度范围标定后确定；节点到ADC预留小串阻与小电容位置，按MCP3208源阻抗/采样建立时间和实测决定，不能用大电容掩盖问题。输入范围不得越过GND/VREF，长线需保护和机械固定。模拟电位器可用10kΩ，两端3.3V/GND，滑端进对应ADC。

未用模拟通道按手册固定，不悬空；阈值和迟滞要逐垫校准。手工焊好不等于力度已校准。

## 9. 焊接物料与操作顺序

准备匹配2.54mm接口的带方向标记转接/插座、洞洞板或小转接板、适配线束、热缩管、细焊锡、助焊剂、万用表。编码器需要16只10kΩ上拉及可选16只330Ω串阻；LED需要13只1kΩ；音频时钟与位时钟源端预留22–47Ω串阻；模块去耦按实际板补充。不要给排母/排针臆定机械朝向，先试装。

推荐顺序：

1. **核实板卡与模块。** 对照型号、修订、连接器位置及模块正反面丝印。未确认前只做外设端和可拔插线束。
2. **全部断电。** 拔掉FPGA电源、USB数据线、C3/Teensy USB及音频相关供电；焊接时不让任一信号侧带电。
3. **做地线与电源支路。** 使用不同颜色和标签，单独检查短路、反接、焊桥；蜂鸣档短暂充电提示需结合电阻读数判断，不机械要求所有电源阻值相同。
4. **先焊一只编码器。** 验证A/B/C触点和上拉阻值后再复制其他7只；对每条线贴旋钮号和针号。
5. **做两组UART线束。** 分别标C3/Teensy及TX/RX/GND，保持两路独立。
6. **做DAC、麦克风及短时钟线束。** 数据与位时钟分清，模式/电源按实际模块确认；初测不接高音量监听。
7. **做LED板。** 每灯单独电阻；先低压测试极性，不把板卡5V针误当信号。
8. **有需要才做FSR/ADC。** 一片一组验证再扩，不在USB主方案中重复焊。
9. **通电前逐线核对。** 线束两端标签、针号、电源/地、相邻短路、输入输出方向，特别核对J23-11/12和J24/J26-1/2/3/4。
10. **分阶段上电联调。** FPGA/模块电源正确后，下载已审查的新扩展固件，先UART身份、再编码器、时钟/I²S、低音量音频、麦克风、LED和组合演奏；失败停在当前阶段查因。

不得直接在BGA球位飞线；不得带电焊；不得在旧位流下仅凭“接线没冒烟”判新功能完成。

## 10. 焊后必须补齐的软件与检查

需要一个真实板级封装：把本文针表映射到完整扩展逻辑，内部化panel_values等调试总线，处理按钮低有效、共享麦克风时钟、未用输入及板载PA_EN，保留已审核DVI/PC UART。不能让编译器把宽调试总线自动铺到外部管脚。

按最终电路建立音频时钟、跨域、外部输入/输出约束；完整配置必须重新PnR和审查建立/保持/脉宽，先SRAM短测再Flash。本文只生成引脚规划表，不生成“已经通过”的可下载位流，也不改变当前默认发布。

首次检查：

- 确认Bank2/3/4/5实际3.3V；外部输入无5V。
- C3、Teensy分别能取得固件身份，1Mbaud消息无CRC错误。
- 8旋钮慢/快/正反转都改变正确参数，无静止跳变。
- J23-39输入24.576MHz，DAC BCK约3.072MHz、WS约48kHz；逻辑分析确认标准I²S对齐。
- 麦克风数据与共享BCK/WS匹配，未接麦克风时歌手状态正确；不能把板载模拟耳麦口当已经接入的I²S麦克风。
- LED按曲目音高/节拍正确，USB垫16格和力度、延音、拔插释放正常。
- 上位机验证能力、录制和重放；正式声音/时延/长稳按83项验收标准继续。
