# 面板更新：六个可按压旋钮、四个独立按键

用户已确认：保留六旋钮的旋转功能，启用六个 SW 按压开关，独立按钮由八个改为四个；屏幕已更正为套餐自带的 J20 RGB 排线 LCD；实际分辨率正在用官方配套时序实测确认，不使用 HDMI。
此文件替代旧版“6旋钮8按键”中的操作及数字按键分配。摇杆双轴、四推子和旋钮 A/B 接线继续保留。
状态：交互与接线规划；当前上板音频程序尚未接入外接面板。LCD UI 单独构建、审核、SRAM 验证，不写 Flash。

## 操作分配

| 控件 | 旋转 | 短按 |
|---|---|---|
| 旋钮1 | 主音量 | 紧急总停音，清除声音及效果尾音 |
| 旋钮2 | 曲谱速度 BPM | 开始／结束事件录制 |
| 旋钮3 | 当前声部表情 | 当前表情恢复默认 |
| 旋钮4 | 当前演奏声部／音色 | 切换屏幕页面 |
| 旋钮5 | 当前声部起音 | 上一歌曲 |
| 旋钮6 | 当前声部释放 | 下一歌曲 |
| 独立键1 | — | 播放／从头重播 |
| 独立键2 | — | 停止 |
| 独立键3 | — | 八度 − |
| 独立键4 | — | 八度 ＋ |

不把“停止后从头重播”标为暂停续播；当前播放协议不具备真正暂停。
旋钮4统一演奏与参数编辑目标，不再另设上一／下一音色按钮。
声部切换必须等待 FPGA 归属确认；冲突显示“声部被占用”，不能只改变屏幕名称。
现有固定声部架构的归还可能等待小节，暂停态切换还需完成协议／所有权衔接，不能直接强抢其他席位。

## 八度和音高

半音布局初始 60..75，八度档位 −3..+4，每档整组 ±12：最低 24..39，最高 108..123，无越界音。
切换只影响后续起音；已按住的音符保留原 note、epoch、serial，松开按原身份释放。
本次不把“低编号归一化”误称为八度功能：C3 v7.1 的 `60 + MIDI编号 % 24` 只是当前预设演示适配，正式键位表需替代它。
鼓组模式不把八度当旋律移调，屏幕显示“不适用”。
录制应保存最终发出的音高、音色选择及八度状态，和现有仅记录原始 MIDI 的手机记录区分。

## 十路按压接线

以下均为低有效，常开触点另一端 GND，信号经 10kΩ 上拉至 3.3V；模块已有上拉时先确认电压，避免重复或 5V 上拉。
旋钮 SW 与 A/B 独立；核对模块 SW/GND 或裸开关触点，不能把编码器 A/B 公共脚当按压开关。

| 输入 | 接口 | 球位 | 功能 |
|---|---|---|---|
| enc_sw_n[0] | J26-7 | B19 | 总停音 |
| enc_sw_n[1] | J26-8 | A19 | 录制 |
| enc_sw_n[2] | J26-5 | A17 | 表情复位 |
| enc_sw_n[3] | J26-6 | A18 | 页面 |
| enc_sw_n[4] | J23-31 | W26 | 上一歌曲 |
| enc_sw_n[5] | J23-32 | W25 | 下一歌曲 |
| panel_key_n[0] | J23-33 | U26 | 播放 |
| panel_key_n[1] | J23-34 | V26 | 停止 |
| panel_key_n[2] | J23-35 | W20 | 八度 − |
| panel_key_n[3] | J23-36 | Y20 | 八度 ＋ |

J23-35 原为预留摇杆 SW，本版改为八度减，摇杆 SW 留空；摇杆 X/Y 不变。
J23-36/Y20 依据本地官方 Rev1.2、Rev1.5 原理图连接器文本核对；仍需实物针序和模块电压检查，不等同已焊接验收。
板载 S0/S1/S2 继续保留播放、停止、总停音。以上十路新信号尚未进入当前20引脚 SRAM 候选的 CST。
INMP441 沿用独立 SCK=J23-37、WS=J23-38、SD=J23-8；PCM5102 为 J23-5/6/7。两者与新按压引脚不冲突。

## LCD UI

首屏为演奏台：实体垫音色、八度、最后音高／力度、真实活跃发声数、16音高触发格、C3垫桥心跳、播放状态、主音量、BPM、面板操作提示。
当前 UI 直接读取 FPGA 接收事件与引擎状态；触发格表示收到敲击，真实声音分配由独立“发声数”显示。
八度尚未接入时标“+0 固定”；录制／页面／选曲等按压标为待接入，不显示虚构成功状态。
后续参数／曲谱／记录页面以相同风格扩展，在实际协议与面板控制实现后启用。
已有640×480 UI绘制内核将适配LCD有效区。画面为纯 RTL 像素流水线、字模 ROM 和帧边界状态快照，不依赖电脑或手机绘图。
