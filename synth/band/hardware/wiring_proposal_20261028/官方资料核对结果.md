## 核对结论

1. 完整引脚表的44个新增信号，在上述两版原理图第16页的连接关系一致，保留原分配。44个包含仅用于可选FSR方案的6个ADC信号；USB打击垫方案不需要焊这些ADC。
2. J24、J26的1/2脚为3.3V，3/4脚为GND；J23的11脚为5V，12脚为GND，40脚是V22信号，不是地。这里是原理图连接器编号，不能套用其他PMOD产品的针序。
3. 官方CST确认J24、J26的全部16个编码器信号球位。J23信号逐一与两版原理图核对。连接器针号是插线位置；球位仅用于FPGA约束，不在BGA底部焊线。
4. 44个新增信号均不与LCD显示、背光、触摸引脚重合。LCD接口虽然标注R/G/B各8位，但原理图把各色最低2位接地，实际FPGA输出18位颜色数据，另加CLK/HS/VS/DE。
5. **LCD触摸接口与S0～S3共用K16、F15、G15、G16。** 触摸的XR/YD/XL/YU分别接J20-37/38/39/40。若屏带四线电阻触摸，不可把它和四个按键当成独立资源使用；本方案不启用触摸驱动。是否接有触摸膜取决于实际屏模块。
6. PMOD0_IO1在扩展口页写L22，但BTB页及官方CST为N26，资料有标注矛盾。本方案不用J22/PMOD0，故不受影响。新版另有J23-29/30的DM网络配置，本方案也避开这两脚。
7. 官方可下载的底板位号图是较早的4071d（2023年），不能把其朝向直接当成照片中底板的最终针序。可使用实物1脚标记/方焊盘，配合断电地线通断检查定位；不要仅凭照片左右方向插线。

## 关键通信接线速查

| 外设端 | FPGA底板接点 | 球位 |
|---|---|---|
| ESP32-C3 GPIO4，配置UART TX | J23-1 | U16 |
| ESP32-C3 GPIO5，配置UART RX | J23-2 | V16 |
| Teensy4.1 pin1/TX1 | J23-3 | U15 |
| Teensy4.1 pin0/RX1 | J23-4 | V17 |
| DAC BCK与I²S麦克风BCLK | J23-5 | W21 |
| DAC LRCK与I²S麦克风WS | J23-6 | Y21 |
| DAC DIN | J23-7 | P21 |
| I²S麦克风SD/DOUT | J23-8 | U17 |
| 各模块信号公共地 | J23-12 | GND |
| 24.576MHz、3.3V CMOS有源时钟OUT | J23-39 | U22 |

C3的GPIO4/5是桥接固件的UART映射，不是固定的USB引脚。UART交叉连接，TX接对端RX。C3支持BLE，不支持经典蓝牙SPP；手机端要使用兼容BLE的协议/应用。

八个编码器、LED、可选ADC的逐针接线见“完整引脚表.md”；供电、阻容、焊接步骤见“先读_完整焊接方案.md”。

## 供电和当前软件状态

FPGA沿用原厂供电方式；ESP32-C3与Teensy初期分别USB供电，只与FPGA连接公共地及信号，不并联各板5V/3.3V输出。编码器使用3.3V上拉。DAC的VIN究竟使用5V还是3.3V取决于具体模块稳压电路，官方FPGA图纸不能代替外设模块资料。

此次完成的是官方资料和接线核对，没有修改或烧录固件。板上当前PT8211+DVI版本不会自动驱动这些新增外设；新扩展版仍需板级顶层、CST/SDC、布局布线时序及上板联调。板载RGB屏也需要RGB驱动，不能由现有DVI输出直接替代。

原理图一致不等于实物电压和焊接已验收。接通前应定位1脚、断电检查短路及地线，再检查供电电压；实际模块电源脚仍按其自身资料接线。
