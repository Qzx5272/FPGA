# 星群 0.2：手机至 FPGA 独立串口

原有改色、单键映射、曲谱文件与打击垫事件记录保留。新增“演奏”页：

- 从实际 FPGA 身份回包读取构建ID和能力；未收到 bit12 能力时禁止演奏。
- 控制板载事件曲目的开始/停止；显示当前播放状态、活跃槽数及选定轨道归属。
- 16个触摸键使用手机保存的键位方案，支持按下/松开、多键及力度设置。
- 先申请 source3 声部归属，再使用板端 epoch 起音；释放保留原 epoch/serial。
- 表情参数只在拥有声部后发送。切换页面/轨道、进入后台时释放手机音符。
- 手机每250ms查询状态，停止心跳后由 FPGA 约500ms席位租约释放；C3断链也发送source3释放。

新增 GATT：服务与0.1相同；c205为手机→FPGA写入，c206为FPGA→手机通知。
采用现有34字节V4事件协议，BLE按20+14字节分段，双方独立CRC校验。
C3只接受source3及受限命令集，添加64个零保护字节，以1Mbps通过GPIO4/5发送。
PC原串口保持独立，两个输入均先解析再仲裁；FPGA回包同时送PC和C3。

独立 FPGA 候选基于 `pt8211_dvi_8994dbe5e358` 快照，新增两个固定引脚，关闭上电自动播放。
保留PT8211、DVI、S0/S1/S2，未接入外置PCM5102/INMP441音频路径。
构建：`D:/StarclusterBuilds/phone_uart_20261031_a`，构建ID `0x20261031`。
实际构建/时序/加载/板测结果以 `../../evidence/phone_fpga_20261031/` 为准。
不修改 `CURRENT_RELEASE.json`，仅在审查通过后加载SRAM；Flash启动程序保持原版本。

手机曲谱上传、实际音频回传尚未接入。
后续 C3 v7 已添加实体打击垫至 FPGA 的音符转发，详情见 `../esp32c3_pad/PAD_AUDIO.md`；
烧录、回包和实物听音的验收状态以对应 evidence 为准。
此时“记录”页记录的是实体垫回传事件，不包含手机触摸键动作。

主机测试：`tests/FpgaWireTest.java` 对照 Python Event，验证34字节完全一致和CRC损坏拒绝；
`tests/FpgaControllerTest.java` 使用计时/GATT存根验证身份门控、BLE分片、松手取消等待、
归属冲突、原始NoteOff身份、后台释放和超时。存根测试不代替真实蓝牙或声音验收。
