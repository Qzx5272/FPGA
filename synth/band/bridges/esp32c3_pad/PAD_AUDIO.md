# C3 v7 实体打击垫音频桥

链路：SMC-PAD Pocket BLE MIDI → C3 → GPIO4/5 UART → FPGA → 板载 PT8211。
不要求手机保持连接；手机的改色、记录和独立触摸演奏继续保留。

实体垫固定使用 source 2、part 8（拨弦）；手机使用 source 3。
启动后验证 FPGA bit12，主动申请 part 8 并每 100 ms 查询续约。
已有其他席位占用时不会强行抢占。手机可使用其他声部，实体垫占用期间手机不能接管拨弦。
FPGA 已停止时，旧席位的待归还状态仍可能等待下一小节；首次切换联调已重新加载相同 SRAM 位流清空旧状态。

按下保留 MIDI 力度；v7.1 将低编号 0..47 映射为 `60 + 编号 % 24`，48..127 原样发送。
实测当前预设发出 7、10、11 等低编号，旧版只映射 24..39 导致低音不可闻，已修正。
这是 C3 的演示映射，没有改写打击垫预设。32 个 channel/note 触点独立跟踪；
松开使用原始 epoch/serial，力度为零的 NoteOn 按 NoteOff 处理。
CC120/123、设备复位、BLE 断开、接收溢出和 UART 超时均有释放处理。
手机队列和打击垫队列分离轮流发送；手机断开只释放 source 3。
等待归属超过 300 ms 的敲击取消，不延迟补发。尚未测量端到端延迟，不能据此宣称满足 10 ms。

测试：`g++ -std=c++11 test_pad_fpga.cpp -o test_pad_fpga.exe` 后运行。
证据：`../../evidence/pad_audio_20261031/`。具体听音验收见 result.json。
FPGA 仍为手机联调 SRAM 程序，断电回到原 Flash 镜像；本轮未写 FPGA Flash。
